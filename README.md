# ToDoSimple
(05.2024-06.2024)
Дипломный проект по разработке андроид-приложения (java) для работы с задачами с использованием современных технологий.
Позволяет пользователю вести список задач в удобном современном интерфейсе, создавать папки. Сервис работает с облачной базой данных,
что позволяет работать на разных устройствах, регистрация на основе логин/пароль и гугл аунтефикация.

## Требования
- minSDK = 34

## Технологии
- Java
- FireDataBase
- Google authentication
